차주익(chajuick) 개인 포트폴리오. 2023년 판(`portfolio-2023`)을 다시 지은 것.

## 2023년 판에서 바꾼 것

| 2023 | 2026 | 이유 |
|---|---|---|
| CRA + HashRouter (`/#/intro`) | Next.js App Router 정적 라우트 | SEO 색인, OG 미리보기, 공유 링크 |
| `overflow-x: scroll` 가로 스크롤 강제 | 일반 세로 스크롤 | 스크롤바 상시 노출, 세로 스크롤 봉인 해소 |
| 폴더 아이콘 2번 클릭 → 모달 | 카드 → 케이스 스터디 페이지 | 내용을 숨기지 않음 |
| SWOT 자기소개 (약점·위기 나열) | 문제 → 판단 → 결과 케이스 스터디 | 포트폴리오는 자소서가 아님 |
| 컴포넌트마다 미디어쿼리 6벌 | Tailwind 반응형 유틸 | 유지보수 |
| 다크 고정 | 라이트/다크 (`next-themes`) | 사용자 선택 존중 |
| 소스맵 프로덕션 노출 | 기본값(비노출) | 소스 유출 |

## 구성

왼쪽은 붙박이 신원(`Identity`), 오른쪽은 흐르는 작업이다.
자기소개를 한 화면 가득 보여준 뒤에야 작업이 나오는 구조를 버렸다 —
첫 화면에서 주장과 증거가 같이 보여야 한다.

마스코트는 히어로의 주인공이 아니라 내비와 푸터의 마크다.
작게 두면 커서를 따라가는 눈이 캐릭터가 아니라 디테일로 읽힌다.

계승한 것: 다크 톤, 산세리프 디스플레이 타이포, 모니터 얼굴 마스코트.
마스코트는 눈동자 커서 추적만 남기고 웃는 입과 말풍선은 뺐다. 살아있다는 신호는 화면 안에서 깜빡이는 커서가 대신한다.

## 규칙

**색은 `src/app/globals.css`의 CSS 변수로만 정의한다.** 컴포넌트에 색을 직접 쓰지 않는다.
다크 모드에서 흰 배경에 흰 글씨가 나오는 사고는 전부 이 규칙을 어겨서 생긴다.
예외는 `src/app/opengraph-image.tsx` 하나 — 서버에서 PNG로 굽는 그림이라 CSS 변수를 읽지 못한다.

**모노스페이스와 넓은 자간은 라틴 전용이다.** 한글에는 `label`, 라틴에는 `label-en`을 쓴다.
JetBrains Mono에 한글이 없어서, 한글에 모노를 걸면 시스템 폴백 글꼴이 글자를 낱개로 벌려놓는다.
`word-break: keep-all`도 같은 이유로 body에 걸어둔다 — 한글은 어절 안에서 끊으면 읽히지 않는다.

**스크롤 연출은 내용을 감추는 방식으로 만들지 않는다.** 감추는 CSS는 인라인 스크립트가 붙인
`html[data-js]` 안에만 산다. 스크립트가 실패하면 연출만 사라지고 내용은 그대로 보인다.
서버 HTML에 `opacity: 0`을 박으면 JS가 죽는 순간 페이지가 백지가 된다.
